# Customs Regulation Monitor

Real-time monitoring and alerting system for international trade regulation changes across major markets.

## Features

- Track regulation updates from 50+ countries
- AI-powered relevance filtering for your business
- Daily digest emails with actionable changes
- Historical compliance data archive

## Quick Start

```bash
pip install -r requirements.txt
python3 monitor.py --track china,us,eu --keywords "certificate of origin,apostille"
```
